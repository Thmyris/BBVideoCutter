# Changelog

What changed in each release. Newest first. "Unreleased" is everything
since the last release; it becomes the next version's notes (which the
app's update box shows as "What's new").

## Unreleased (since v1.2)

- **The app's icon on its windows** instead of the default feather.
- **The version in the window title.**
- **The update box shows what every skipped version brought**, each under its own version.
- **Cut Start and Cut End show 00:00:00.000 before a video is open**, instead of being empty.
- **A shorter About box.**
- **Saving the whole video as a scene is refused**, with a box that says so.
- **So is saving a scene 0.000 s long.**

## v1.2 (2026-10-27)

- **Improved auto-updating pipeline.**

## v1.1 (2026-10-27)

- **Linux (beta):** a `.deb` package for Ubuntu 24.04+ and a `.tar.gz`
  for other distros. Needs `ffmpeg` and `libmpv2` (the `.deb` installs
  them).

- **UI:** Improved design and performance.

## v1.0 (2026-10-26)

First public release: Windows installer (`BBVideoCutter-Setup.exe`) and
portable zip (`BBVideoCutter-Portable.zip`).
